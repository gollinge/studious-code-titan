Studious Code Titan
===================

A Python learning app for kids. Everything runs on this computer; nothing
needs to be installed and no internet connection is required.

To start
--------
1. Unzip this folder somewhere permanent (for example your Documents folder).
   Don't run it from inside the zip file.
2. Double-click "Start Studious Code Titan.bat".
3. The app opens in your web browser at http://127.0.0.1:8765/
   A black window also opens - keep it open while using the app.

To stop
-------
Close the black window.

Notes
-----
- Lesson progress is saved in the browser. Use the same browser each time to
  keep your progress.
- The first time you start it, Windows SmartScreen may say "Windows protected
  your PC". Click "More info", then "Run anyway".
- If Windows Firewall asks about python.exe, you can click Cancel: the app only
  talks to this computer.
