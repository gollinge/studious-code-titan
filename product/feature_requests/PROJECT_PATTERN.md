Backlog Item — Project Studio UI/CX Pattern

Goal:
Create a reusable project-building experience for Creative Projects I and all future project modules.

Purpose:
Project modules should help the learner consolidate concepts, build confidence, and create personally meaningful programs. The UI should shift from lesson-following to project-building.

Core Experience:
Learner chooses a project, reviews a short brief, builds through milestones, tests frequently, uses optional hints, then remixes or personalizes the result.

Required UI:
- Project Gallery
- Project Brief
- Build Studio
- Milestone Checklist
- Optional Hints Drawer
- Remix Ideas
- Save / Reflection Step

Build Studio Layout:
- Left panel: project brief, milestones, hints, remix prompts
- Center panel: Python editor
- Right panel: output, errors, run results, completion cues

Validation:
- Use flexible milestone detection rather than exact-output grading.
- Prefer checks such as:
  - uses at least one function
  - uses input()
  - uses if/else
  - has multiple endings
  - includes at least one loop
- Do not require one exact solution.

Creative Projects I Initial Templates:
1. Text Adventure
2. Quiz Game
3. Pet or Creature Simulator

Design Principle:
The learner should feel they are building something of their own, not completing another worksheet.
